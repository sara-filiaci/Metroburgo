# Metroborgo Survey Analysis

This repository contains a descriptive analysis of the survey results related to the Metroborgo project and the municipality of Montalto delle Marche.

The analysis distinguishes between two groups:

* residents and regular visitors;
* non-resident or occasional visitors.

The notebooks include:

* dataset cleaning and validation;
* management of missing responses and partially completed questionnaires;
* sociodemographic analysis;
* analysis of visit characteristics;
* calculation of frequencies, percentages, means, and medians;
* grouping of survey statements into thematic areas;
* analysis of the perceived effects of the project;
* analysis of income, property value, and economic investments.

## Repository files

* `analisi.ipynb`: Italian version of the Jupyter Notebook;
* `analysis.ipynb`: English version of the Jupyter Notebook;
* `README.md`: project description.

The original dataset is not included in this repository. However, the notebooks contain the saved outputs of the analysis, allowing the results to be viewed directly on GitHub.

## Technologies

* Python
* pandas
* Jupyter Notebook

Data visualizations and the final interpretation of the results are developed separately in a dedicated presentation.

# Analisi del questionario Metroborgo

Questo repository contiene un’analisi descrittiva dei risultati del questionario relativo al progetto Metroborgo e al territorio di Montalto delle Marche.

L’analisi distingue due gruppi:

* residenti e frequentatori abituali;
* visitatori non residenti o non abituali.

I notebook comprendono:

* pulizia e controllo del dataset;
* gestione delle risposte mancanti e delle compilazioni parziali;
* analisi sociodemografica;
* analisi delle caratteristiche della visita;
* calcolo di frequenze, percentuali, medie e mediane;
* sintesi delle affermazioni in aree tematiche;
* analisi degli effetti percepiti del progetto;
* analisi di reddito, patrimonio e investimenti economici.

## File presenti

* `analisi.ipynb`: versione italiana del notebook Jupyter;
* `analysis.ipynb`: versione inglese del notebook Jupyter;
* `README.md`: descrizione del progetto.

Il dataset originale non è incluso nel repository. I notebook contengono però gli output salvati dell’analisi, permettendo di visualizzare direttamente su GitHub i risultati ottenuti.

## Tecnologie utilizzate

* Python
* pandas
* Jupyter Notebook

Le visualizzazioni grafiche e l’interpretazione conclusiva dei risultati vengono sviluppate separatamente in una presentazione dedicata.
